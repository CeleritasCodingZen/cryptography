## What is Kryptos?

**Kryptos** is a web platform for people who enjoy solving cryptography puzzles and logic-based challenges.

The idea is simple:

- Solve daily cipher challenges  
- Compete on leaderboards  
- Build solving streaks  
- Unlock achievements  
- Improve logical thinking and pattern recognition  
- Learn cryptography concepts in a fun way  

This project is being built as a complete experience — not just puzzles, but a full competitive platform with accounts, rankings, history, and an admin control panel.

## Run Locally

Clone the project:

```bash
git clone <your-repo-url>
cd kryptos
```

Install dependencies:

```bash
npm install
```

Setup environment variables:

Create a `.env` file:

```env
DATABASE_URL=
JWT_SECRET=
RESEND_API_KEY=
```

Run:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
